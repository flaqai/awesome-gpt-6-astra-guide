## Что такое Astra

Astra — модель OpenAI для сложных рассуждений, программирования, исследований и многоэтапных задач. Она принимает текст и изображения и выдаёт текст. Работа в браузере, запуск программ и создание видео требуют инструментов в используемом приложении.

| Модель | `gpt-6-astra` |
| --- | --- |
| Контекст | 1,050,000 tokens |
| Максимальный вывод | 128,000 tokens |
| Уровень рассуждений | `low` · `medium` · `high` · `xhigh` · `max` |

[Официальная документация](https://developers.openai.com/api/docs/models/gpt-6-astra) · [Настройки и расширенные возможности](https://developers.openai.com/api/docs/guides/latest-model)

## Начните без программирования

Выберите Astra в продукте, к которому у вас есть доступ, приложите материалы и попросите небольшой результат. Например:

```text
Спланируй двухдневное мероприятие для кофейни. Бюджет — 2000 юаней, сотрудников двое. Подготовь правила, расписание, подробный бюджет и три рекламных сообщения. Проверь итоговую сумму и обозначь допущения.
```

## Запустите первый пример

Используйте Python 3.10+ или Node.js 20+ из корня репозитория. Скриптам достаточно встроенных библиотек; устанавливать пакеты не нужно. Сначала бесплатно просмотрите запрос:

```bash
python3 examples/astra.py text --dry-run
node examples/quickstart.mjs --dry-run
```

Для реального вызова задайте в терминале `OPENAI_API_KEY`: ключ проекта OpenAI с доступом к Astra. См. [настройку](docs/quickstart.md#用-api-开始). Не включайте ключи в код или снимки экрана. `--dry-run` не обращается к сети; реальные запросы платные. Примеры напрямую используют OpenAI API. Наличие модели на Flaq.ai проверяйте отдельно.

```bash
python3 examples/astra.py text --prompt 'Спланируй двухдневное мероприятие для кофейни. Бюджет — 2000 юаней, сотрудников двое. Подготовь правила, расписание, подробный бюджет и три рекламных сообщения. Проверь итоговую сумму и обозначь допущения.'
python3 examples/astra.py vision --image assets/screenshots/iphone-archive.png
python3 examples/astra.py research
python3 examples/astra.py extract
node examples/quickstart.mjs
```
