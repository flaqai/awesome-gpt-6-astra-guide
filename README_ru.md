## Что такое Astra

Astra — модель OpenAI для сложных рассуждений, программирования, исследований и многоэтапных задач. Она принимает текст и изображения и выдаёт текст. Работа в браузере, запуск программ и создание видео требуют инструментов в используемом приложении.


[Официальная документация](https://developers.openai.com/api/docs/models/gpt-6-astra) · [Настройки и расширенные возможности](https://developers.openai.com/api/docs/guides/latest-model)

## Начните без программирования

Выберите Astra в продукте, к которому у вас есть доступ, приложите материалы и попросите небольшой результат. Например:

```text
Спланируй двухдневное мероприятие для кофейни. Бюджет — 2000 юаней, сотрудников двое. Подготовь правила, расписание, подробный бюджет и три рекламных сообщения. Проверь итоговую сумму и обозначь допущения.
```

## Используйте прямо в клиенте

Войдите через ChatGPT: для начала не нужен ключ API. Доступ к Astra и лимиты зависят от аккаунта и рабочего пространства.

### ChatGPT

Войдите в ChatGPT; для готовых материалов выберите Work. Выберите Astra в меню модели/Power, при необходимости откройте Advanced. Прикрепите бюджет и попросите сравнить 24 и 32 участника.

### Codex

Войдите в клиент Codex; в объединённом приложении переключитесь на Codex. Откройте локальную папку, создайте задачу с Astra и попросите запустить упражнения, предоставить файлы и результаты реальных проверок.

### Codex CLI

[Установить CLI](https://learn.chatgpt.com/docs/cli). Установите CLI с официальной страницы и запустите в папке проекта. При первом запуске выберите Sign in with ChatGPT. В сеансе проверьте Astra через /model, настройки через /status, затем опишите задачу.

```bash
codex -m gpt-6-astra
```
