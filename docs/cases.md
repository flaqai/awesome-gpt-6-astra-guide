# 12 个原创 Astra 实践练习

[中文首页](../README_zh.md) · [English](../README.md) · [运行教程 / English walkthrough](original-lab.md)

由 **[flaq.ai](https://flaq.ai/) 团队**围绕虚构的 Paper Circuit Studio 纸电路工作室整理。前三项已有可离线运行的代码和报告；后九项是拓展任务说明，尚未实现或实测，不把设想包装成模型成果。原先收录的社区作品移至 [延伸阅读](community-references.md)，保留作者与原帖链接。

## 三个可以立即运行的案例

```bash
python3 examples/field_lab.py
```

<a id="case-01"></a>

### 01 · 带预留金的活动预算

![原创预算报告](../assets/screenshots/workshop-budget.png)

**输入**：2,600 元、24 人、三项固定费用和两项人均费用。**输出**：支出 2,168 元、预留 432 元，满足 10% 预留目标。

**交给 Astra 的任务**：根据 `results.json` 解释哪些成本随人数变化；建议两种保持预留金的方法，并逐项复算。**验收**：用本地结果检查算术；不能把减少成本说成无代价的改动。

<a id="case-02"></a>

### 02 · 可按帧验收的纸电路分镜

![原创分镜报告](../assets/screenshots/craft-storyboard.png)

**输入**：准备、制作、分享三个镜头，分别 5、7、8 秒，30 fps。**输出**：连续帧区间 [0,150)、[150,360)、[360,600)，总计 20 秒。

**交给 Astra 的任务**：将第二个镜头延长一秒，给出维持总时长的调整方案。**验收**：把建议写回资料后重新运行，检查总帧数及区间连续性。这里的插画由 SVG 基本图形绘制，没有引用他人贴图；输出不是视频文件。

<a id="case-03"></a>

### 03 · 根据证据做发布验收

![原创验收报告](../assets/screenshots/release-review.png)

**输入**：5 项虚构检查值与目标值。**输出**：3 项通过；R02 手机溢出 18 px、R03 缺少 2 个图片说明，报告显示 HOLD。

**交给 Astra 的任务**：为每个未通过项列出编号、负责人、现状、目标与修复步骤。**验收**：不把未通过项遗漏，不将建议写成已完成的修复。在 Codex 中直接要求读取 `results.json` 并解释失败项；也可在 ChatGPT 上传报告进行分析。

## 九个拓展任务（尚未实现）

以下任务都可沿用 [原创资料](../examples/fixtures/studio-brief.json)。给 Astra 提供任务与验收条件，逐项实现后再记录运行证据。

| # | 任务 | 给 Astra 的明确要求 | 完成时如何验收 |
| --- | --- | --- | --- |
| 04 | 报名容量规划 | 生成 12、24、32 人的费用比较，保持固定成本不变 | 与三次本地运行结果逐项对照 |
| 05 | 采购清单导出 | 从人均材料费拆出用户提供的数量与单价；缺资料就提问；导出 CSV | 数量和金额有来源，CSV 可重新读取 |
| 06 | 预算变更说明 | 比较两份 `results.json`，输出金额变化和对应假设 | 不把人数变化误写成涨价 |
| 07 | 多语言分镜字幕 | 将三个镜头字幕译为中英双语，保留镜头编号和时长 | 三个编号对应，字幕不擅自承诺产品效果 |
| 08 | 镜头清单校验器 | 检测重复编号、零时长、超出目标时长，并输出可读错误 | 无效输入失败；有效的三镜头资料通过 |
| 09 | 无障碍文字报告 | 用结构化文本描述三张图的关键信息，说明 PASS/FIX 的文字含义 | 不依赖颜色即可知道结论 |
| 10 | 修复任务看板 | 根据失败检查创建本地任务列表，保留负责人和目标值 | 仅 R02、R03 出现在默认待修复列表 |
| 11 | 报告输入编辑器 | 提供人数和预算输入，修改后重新计算；不允许把字符串当数字 | 默认和 32 人场景与 Python 一致 |
| 12 | 发布前后证据对比 | 读取两份模拟验收资料，区分修复、新增问题和仍未通过项 | 每条变化有旧值、新值和编号，不推断真实网页状态 |

不要仅凭模型的总结认定任务完成。保存输入、生成代码、运行命令和实际输出，明确哪些是虚构数据、哪些是实际测量。[进一步工作流](workflows.md) · [验证记录](verification.md)
