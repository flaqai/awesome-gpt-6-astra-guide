Source: [field_lab.py](../../examples/field_lab.py) and [studio-brief.json](../../examples/fixtures/studio-brief.json), covered by this repository's [MIT License](../../LICENSE). The screenshots preserve the actual browser rendering without image editing. Source and asset SHA-256 hashes are recorded in [manifest.json](manifest.json); hashes identify files, not a legal authorship certification.

Reproduce from the repository root:

```bash
python3 examples/field_lab.py --out outputs/reproduce
python3 -m http.server 8768 --bind 127.0.0.1 --directory outputs/reproduce
```

Open each generated `.svg` at `http://127.0.0.1:8768/` in a browser and capture the report. SVG dimensions are 1280 × 720; browser font rendering and pixel density may change PNG bytes. Regenerated SVG bytes should match the committed vectors with the unchanged generator and fixture. Use a fresh output directory for repeated runs, or explicitly add `--overwrite`.
